[size=4][color=#7f8c8d]统一配置化 · 属性运行时 · 装备成长 的 Minecraft Java 属性插件[/color][/size]

[size=5][b][color=#2980b9]■ 插件简介[/color][/b][/size]

[b]SX-Attribute[/b] 是一款面向 Minecraft Java 服务端的 RPG 属性插件。装备 Lore、动态属性、状态效果、战斗规则和成长系统都可以围绕统一的属性运行时配置，让职业、装备构筑、元素关系和怪物机制不再依赖零散的硬编码逻辑。

我听说，世间器物各有其用，就像一柄好剑，若能削铁如泥，便算尽了它的本分。SX-Attribute 这个插件，在我的世界Java版里，就像一把趁手的工具——它能把属性分得清清楚楚，让玩家知道什么装备该配什么效果，什么职业该有什么长处。这不正是礼法里说的“各司其职”吗？

有人或许会问：难道就没有比它更好的插件吗？那我倒要反问一句：若有一把刀，既能切菜又能劈柴，但切菜不如菜刀利落，劈柴不如斧头干脆——这样的东西，能算得上“好用”吗？SX-Attribute 不贪多，只把属性这一件事做到明白、稳定、不乱，这就可以说是尽了名分。

所以，若论属性插件，它在我心里，就是最好用的那一个。这不是吹捧，是它自己挣来的体面。

[size=5][b][color=#2980b9]■ Beta 2 核心特性[/color][/b][/size]

[list]
[*][color=#27ae60][b]统一属性定义[/b][/color]：[code]Feature/Attribute/Attributes.yml[/code] 聚合属性分片。一个定义可包含数值字段、Lore 匹配、触发器、条件公式、动作和面板显示。
[*][color=#27ae60][b]配置化战斗扩展[/b][/color]：仅通过 YAML 即可组合元素伤害/抗性、种族克制、Buff、Debuff、低血量效果、药水、粒子、声音、经验和耐久变化。
[*][color=#27ae60][b]来源生命周期[/b][/color]：支持 [code]REPLACE[/code]、[code]REFRESH[/code]、[code]STACK[/code]、[code]MAX[/code]、[code]MIN[/code]、[code]UNIQUE[/code]，可配置层数、时长、标签与持久化。
[*][color=#27ae60][b]多服存储[/b][/color]：来源可使用 MEMORY、SQLite、MySQL 或 PostgreSQL；多服模式由 Redis 负责写锁与失效广播。
[*][color=#27ae60][b]装备成长[/b][/color]：套装/混搭、品质、词缀、强化、升星、重铸、洗练、宝石孔、原版及自定义附魔成长均为独立模块和独立开关。
[*][color=#27ae60][b]伤害粒子限流[/b][/color]：通过 PacketEvents 或 ProtocolLib 压缩客户端收到的原版伤害指示粒子包，不改变伤害数值、生命扣除和击杀结果。
[*][color=#27ae60][b]安全重载[/b][/color]：普通属性分片会先构建并校验新注册表，成功后才替换并重算在线玩家；失败时继续使用旧注册表。
[/list]

[size=5][b][color=#2980b9]■ 物品 Lore 示例[/color][/b][/size]

[code]Name: "&c炎之剑"
ID: DIAMOND_SWORD
Lore:
  - "&6物品类型: 主武器"
  - "&c攻击力: +20"
  - "&c火元素伤害: +15"
  - "&6限制等级: 30级"[/code]

Lore 继续兼容原有属性工作流。新属性字段可以通过 [code]Match[/code] 自动识别并聚合，物品模板同时支持 SX-Item 随机表达式与锁定随机值。

[hr]

[size=5][b][color=#2980b9]■ 动态属性示例：火元素伤害[/color][/b][/size]

[code]Attributes:
  FireDamage:
    Enable: true
    Values:
      damage: { Match: 火元素伤害, Aggregate: SUM, Min: 0, Max: 100000 }
    Triggers:
      - Event: DAMAGE_ATTACK
        When: "<c:<l:self_damage> > 0>"
        Actions:
          - Type: DAMAGE
            Mode: ADD
            Formula: "<c:<l:self_damage>>"[/code]

可用触发器包括装备加载、装备变化、攻击、受击、伤害后、射箭、治疗、经验、击杀、死亡、周期和 API 调用。动作只提供受控原语，例如伤害、治疗、药水、来源增删、火焰、雷击、指令、消息、粒子、声音、经验与耐久，配置不会反射执行任意 Java 代码。

[size=5][b][color=#2980b9]■ 来源与装备成长[/color][/b][/size]

[table]
[tr][td][b]模块[/b][/td][td][b]用途[/b][/td][/tr]
[tr][td]Source[/td][td]技能、职业、临时 Buff、跨服状态与外部插件注入的独立属性来源。[/td][/tr]
[tr][td]SetBonus / Quality / Affix[/td][td]套装与混搭、品质抽取、词缀池、稀有词缀和权重。[/td][/tr]
[tr][td]Enhance / Star[/td][td]独立等级、成功率、消耗、保护与 KEEP / DOWNGRADE / RESET / DESTROY 失败策略。[/td][/tr]
[tr][td]Reforge / Reroll / Socket[/td][td]词缀身份重抽、数值洗练、宝石镶嵌与拆卸损毁。[/td][/tr]
[tr][td]EnchantGrowth[/td][td]原版或自定义成长附魔；真实注册不可用时可配置为纯 Lore 模式。[/td][/tr]
[/table]

所有装备成长状态以物品 NBT 为事实源，Lore 由状态重建。关闭模块不会删除现有 NBT，只会停止对应效果与操作入口。

[size=5][b][color=#2980b9]■ 安装与常用指令[/color][/b][/size]

[list=1]
[*]下载与服务端版本匹配的 [url=https://github.com/Saukiya/SX-Attribute/releases]SX-Attribute[/url]，并与 [url=https://github.com/Saukiya/SX-Item/releases]SX-Item[/url] 一同放入 [code]plugins/[/code]。
[*]如需限制高伤害产生的原版伤害粒子，可选安装 PacketEvents 或 ProtocolLib；同时安装时优先 PacketEvents，失败时自动回退 ProtocolLib。
[*]完整重启服务器生成配置；先在测试服修改 [code]Feature/[/code] 下配置。
[*]普通配置修改后使用 [color=#c0392b]/sxa reload[/color] 重载并检查控制台。
[/list]

[table]
[tr][td][b]指令[/b][/td][td][b]功能[/b][/td][/tr]
[tr][td]/sxa stats [玩家][/td][td]打开属性面板。[/td][/tr]
[tr][td]/sxa forge [模块][/td][td]打开锻造界面或指定装备模块。[/td][/tr]
[tr][td]/sxa give / save / nbt[/td][td]发放模板物品、保存手持物品、查看 NBT。[/td][/tr]
[tr][td]/sxa source [玩家][/td][td]查看实体属性来源及其贡献。[/td][/tr]
[tr][td]/sxa update [玩家][/td][td]重新读取装备属性并刷新 UPDATE 类原版属性。[/td][/tr]
[tr][td]/sxa reload[/td][td]重载物品、随机字符串、属性、来源与装备模块，并重算在线玩家。[/td][/tr]
[/table]

[size=5][b][color=#2980b9]■ 兼容与文档[/color][/b][/size]

[list]
[*]服务端：Spigot、Paper、Folia 及 Bukkit 兼容端。
[*]必需依赖：SX-Item；Vault、PlaceholderAPI、HolographicDisplays、DecentHolograms、RPGInventory、MythicMobs、SkillAPI、PacketEvents、ProtocolLib 为可选依赖。
[*]伤害粒子配置：[code]DamageEvent.DamageParticleLimit[/code] 默认为 8，-1 不拦截，0 完全隐藏；只影响客户端收到的 [code]DAMAGE_INDICATOR[/code] 粒子包。
[*]完整文档：[url=https://github.com/Saukiya/SX-Attribute/tree/3.x/docs]GitHub docs[/url]（安装、属性、物品、配置化模块、JavaScript、外部 API 与发行说明）。
[*]反馈问题请附上服务端版本、SX-Attribute 版本、SX-Item 版本、相关配置和完整日志。
[/list]
