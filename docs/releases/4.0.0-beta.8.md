# SX-Attribute 4.0.0 Beta 8

这是统一配置化重构的第八个公开测试版本，新增用户可配置的属性映射，让力量、敏捷等基础属性按公式转换为攻击力、暴击几率或其它自定义属性。

## 主要变化

- 自定义属性定义新增 `Mappings`，一个源字段可以同时映射到多个内置或自定义目标属性。
- `Scale` 通过 SX-Item 公式引擎计算“每点源属性对应多少目标属性”的倍率。
- 可选的 `Formula` 计算最终映射值；省略或求值失败时自动使用 `value * scale`。
- 映射公式支持 `value`、`scale`、当前定义字段以及 `属性ID_字段` 跨属性变量。
- 映射在玩家全部属性来源聚合后统一计算，并读取同一份原始快照，避免装备拆分、配置顺序或循环映射改变结果。

## 配置示例

```yml
Attributes:
  Strength:
    Enable: true
    Values:
      strength:
        Match: 力量
        MatchMode: CONTAINS
        Aggregate: SUM
        Min: 0
        Max: 100000
    Mappings:
      - Source: strength
        Target: 攻击力
        Scale: "<c:2>"
        Formula: "<c:<l:value> * <l:scale>>"
      - Source: strength
        Target: 暴击几率
        Scale: "<c:2>"
```

以上配置让每点力量增加 `2` 点攻击力和 `2%` 暴击几率。完整逐行注释、同源字段变量与非线性公式示例见 `Feature/Attribute/definitions/custom.yml` 和属性功能文档。

## 升级提示

- 现有服务器的 `custom.yml` 不会被覆盖；需要手动把 `Mappings` 加入自己的属性定义。
- 使用公式型 `Scale` 或 `Formula` 前，请确认已安装兼容版本的 SX-Item，并保持 `Feature/Attribute/Attributes.yml` 中 `Settings.FormulaEngine: true`。
- 修改定义后执行 `/sxa reload`；正式升级 JAR 时仍建议完整重启服务器，不要使用第三方热卸载插件。
- 升级前请备份插件目录，并在测试服检查装备切换、属性面板、攻击伤害和暴击行为。
