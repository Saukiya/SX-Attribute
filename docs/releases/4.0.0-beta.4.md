# SX-Attribute 4.0.0 Beta 4

这是统一配置化重构的第四个公开测试版本，修复部分 Folia 分支因服务端名称不同而未启用区域调度器的问题。

## 主要变化

- Folia 运行环境改为检测区域化服务端核心类，不再依赖 `Bukkit.getName()` 或服务端展示名称。
- 使用自定义名称的 Folia 分支现在会正确调用全局区域调度器和实体调度器，避免退回线程模型不兼容的 Bukkit 调度器。
- 普通 Spigot 与 Paper 不包含该核心类，仍继续使用原有 Bukkit 调度路径。

## 升级提示

- Folia 及其分支建议升级；普通 Spigot/Paper 用户可以直接替换，但不受本次问题影响。
- 替换 JAR 后需要完整重启服务器，不要使用第三方热卸载插件。
- 升级前请备份插件目录，并在测试服确认定时属性、持续伤害、生命恢复和延迟命令等调度行为正常。
