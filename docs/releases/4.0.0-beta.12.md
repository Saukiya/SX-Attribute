# SX-Attribute 4.0.0-beta.12

Adds an optional ProSkillAPI bridge gated by `SkillAPI.Enabled` and the
ProSkillAPI `SX-Attribute.enabled` switch. Both default to disabled.
Use with ProSkillAPI R-1.2.20 and install the `-all.jar` asset.

The bridge registers skill damage and player-cast healing handlers, polls
same-name player attributes, listens for temporary/entity attribute events,
and maintains an empty Lore set-bonus lifecycle marker to avoid adding the
same local bonus again through that source.

## Validation and limitations

- Existing tests and shaded builds passed for the preceding implementation.
- Both plugins enabled together on Paper 1.20.6; this proves startup only.
- The previous Mineflayer report used old ProSkillAPI without SX-Attribute.
- Attribute export can still include imported contributions; complete source
  accounting, expiry/replacement reconciliation and reload rollback are pending.
- Full health authority, formula variables, configurable import/export and
  numerical combat assertions have not been completed.
- True-damage type tagging has not been proven to bypass all SX reductions.
- This pre-release is experimental and does not certify full combat compatibility.
