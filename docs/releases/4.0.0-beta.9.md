# SX-Attribute 4.0.0 Beta 9

这是统一配置化重构的第九个公开测试版本，修复旧版本服务器属性面板显示，以及玩家背包饰品槽指引和属性刷新问题。

本次仅发布源码与说明，未构建或上传插件 JAR，GitHub 自动生成的源码压缩包不能直接放入服务器的 `plugins/` 目录。

## 主要变化

- 修复旧版本服务器属性面板显示不受支持的原版属性并出现 `N/A` 的问题（[#55](https://github.com/Saukiya/SX-Attribute/issues/55)）。属性注册与面板共用最低版本和实际 Bukkit API 检查。
- 自动面板跳过未启用或不受支持的属性；旧 `Message.yml` 和自定义显示行也会过滤已知不可用属性，“显示更多属性”不会重新显示这些行。混合行中任一已知属性不可用时隐藏整行，未知占位符仍保留。
- 恢复 `/sx displaySlot` 指令，在聊天中提示玩家自身背包中的饰品位置（[#56](https://github.com/Saukiya/SX-Attribute/issues/56)）。默认槽位 `17#宝藏`、`26#戒指`、`35#项链` 对应背包三排最右侧，饰品 Lore 须包含对应识别名。
- 修复点击、拖拽、Shift 移动、数字键换位等背包操作后的属性刷新；打开箱子等容器时，下方玩家背包的饰品槽同样会刷新。物品状态在下一 tick 读取，关闭容器时补充刷新。
- 新增 `sx-attribute.displayslot` 权限，默认向所有玩家开放；启用 RPGInventory 联动时，指令会提示使用其装备栏。
- 旧语言文件缺少新指令文本时，使用随包资源中的默认值，保留已有定制且不覆写文件。

## 升级提示

- 本版本继续保持预发布状态。部署对应 JAR 前请备份插件目录并完整重启服务器。
- 现有 `RegisterSlots` 配置可继续使用；槽位编号是 Bukkit 玩家背包编号，`0..8` 为快捷栏，`9..35` 为背包三排。
- Minecraft 1.12.2 不支持新版采集类原版属性；升级 PlaceholderAPI 或调低属性的 `Version` 不会补齐服务端能力。本次修复解决面板显示，不代表旧版本获得了新属性。
- 建议在测试服检查属性面板、饰品放入与取出、跨容器移动，以及 RPGInventory 联动下的装备行为。
