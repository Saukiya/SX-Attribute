# SX-Attribute 4.0.0 Beta 3

这是统一配置化重构的第三个公开测试版本，重点完善装备成长数据与 SX-Item 模板的协作方式，并补齐高伤害场景下的客户端粒子控制。

## 主要变化

- 新增 `NBTAttribute.Nodes`，属性可从物品 NBT 的字符串、列表或嵌套映射读取；纯 NBT 属性物品切换时也会正常触发属性刷新。
- 装备模块将真实状态、计算属性和显示副本拆分到 `.State`、`.Attributes`、`.Rendered` 节点，避免显示 Lore 被重复计入属性。
- 新增 `EquipmentFeature.LoreMode`：`VARIABLE` 默认通过 SX-Item `<l:SXAttribute_<模块>_Lore>` 锁变量安排显示位置，`LORE` 保留直接维护 Lore 的兼容方式。
- SX-Item 自动更新物品模板时迁移装备模块状态，并在 `LORE` 与 `VARIABLE` 模式之间清理旧显示数据，避免成长等级、词缀或宝石状态丢失。
- 新增原版伤害指示粒子出站限流：优先使用 PacketEvents、回退 ProtocolLib，只压缩客户端粒子包数量，不改变伤害、生命和击杀结果。
- 主配置、功能配置、示例物品、随机字符串、插件清单以及 API/架构文档补充了字段约束与设计说明。
- README 与 `docs/` 已按安装、属性、物品、功能、API、架构和发行记录重新整理，并以文档首页作为统一入口。

## 升级提示

- 替换 JAR 后需要完整重启服务器，不要使用第三方热卸载插件。
- `EquipmentFeature.LoreMode` 默认是 `VARIABLE`。SX-Item 模板需要在 Lore 中引用所需的 `<l:SXAttribute_<模块>_Lore>`；旧物品生成器或普通 Bukkit 物品应改用 `LORE`。
- 默认 `NBTAttribute.Nodes` 已包含全部内置装备模块的 `.Attributes` 节点；自定义插件节点可继续追加，路径使用点号分隔。
- `DamageEvent.DamageParticleLimit` 默认为 `8`；`-1` 不拦截，`0` 完全隐藏原版伤害指示粒子。该功能需要 PacketEvents 或 ProtocolLib，二者同时存在时优先 PacketEvents。
- 粒子适配器只在启动时注册。启动时配置为 `-1` 后若要重新启用，需完整重启；已经注册后调整具体上限可使用 `/sxa reload`。
- 升级前请备份插件目录、玩家物品数据和来源数据库，并先在测试服验证既有 SX-Item 模板中的装备成长变量位置。
