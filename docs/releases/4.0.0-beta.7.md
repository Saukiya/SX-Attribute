# SX-Attribute 4.0.0 Beta 7

这是统一配置化重构的第七个公开测试版本，重点修复 Paper 高版本生命压缩、DecentHolograms 浮空字兼容与运行期经济服务检测。

## 主要变化

- 最大生命新增 `HEALTH_SCALED` 与 `ATTRIBUTE_MODIFIER` 两种写入模式；默认模式恢复 3.9.2 的 base value 与客户端血条压缩行为。
- `HEALTH_SCALED` 可通过 `HealthScaled.Enabled` 和 `HealthScaled.Value` 控制显示上限，默认 `40`，即两排红心。
- `ATTRIBUTE_MODIFIER` 保留 beta.6 的固定 UUID 修饰器协议，继续允许外部插件提供 base value，但主动关闭 Bukkit 客户端生命缩放。
- 伤害浮空字统一经过全息提供者抽象，HolographicDisplays 与 DecentHolograms 均支持多行创建、上移和删除。

## 修复的问题

- 修复 Paper 26.1.2 等高版本中，最大生命增加后血条不能按配置压缩的问题。
- 修复仅安装 DecentHolograms 时，攻击触发 HolographicDisplays 类加载错误的问题。
- 修复受伤浮空字读取不存在的 `PLAYER.HOLOGRAPHIC.HURT` 后显示 `Null Message` 的问题；默认语言文件同时保留 `TAKE` 与兼容用 `HURT`。
- 修复经济插件晚于 SX-Attribute 注册 Vault 服务时，出售和修理功能长期判定经济不可用的问题。

## 升级提示

- `Health.Health.Mode` 缺省时自动使用 `HEALTH_SCALED`；需要保留其他插件 base value 的服务器可显式改为 `ATTRIBUTE_MODIFIER`。
- 替换 JAR 后需要完整重启服务器，不要使用第三方热卸载插件。
- 升级前请备份插件目录，并在测试服检查装备切换、重连、伤害浮空字、出售和修理功能。
