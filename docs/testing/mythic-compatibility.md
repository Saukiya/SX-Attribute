242 项 ABI 检查直接读取官方 JAR 的 class 文件，核验完整 JVM 描述符、继承的接口方法和同步字段。
工具不运行 MM、不生成 Java 字节码，不会执行 Gradle 构建。
全部制品的 SHA-256 指纹、逐版本覆盖数及缺失列表保存在 [mythic-abi.json](mythic-abi.json)。
核验脚本见 [check_mythic_abi.py](../../scripts/check_mythic_abi.py)。

制品来源：

- [Mythic 官方 Maven](https://mvn.lumine.io/repository/maven-public/)：`io.lumine.xikage:MythicMobs` 与 `io.lumine:Mythic-Dist`。
- [Spigot 官方 snapshots](https://hub.spigotmc.org/nexus/content/repositories/snapshots/)：`org.spigotmc:spigot-api`。
- [PaperMC 官方制品库](https://artifactory.papermc.io/artifactory/universe/)：`dev.folia:folia-api`。
- Folia 旧版具体快照为 `1.19.4-R0.1-20230527.192927-40`、`1.20.6-R0.1-20240829.045608-5`。
- MM 4.1 的具体快照为 `4.1.0-20170503.035429-71`。
- Bukkit 样本的具体快照为 `1.8.8-R0.1-20160221.082514-43`、`1.12.2-R0.1-20180712.012057-156`、

复验命令示例（JAR 路径由执行者提供，不会自动下载）：

```sh
mise exec python -- python scripts/check_mythic_abi.py \
  --mythic 4.1.0-SNAPSHOT=/path/to/MythicMobs-4.1.jar \
  --mythic 5.13.0=/path/to/Mythic-Dist-5.13.0.jar \
  --bukkit 1.8.8=/path/to/spigot-api-1.8.8.jar \
  --output /tmp/mythic-abi.json
```

## 兼容约束对应表

| 约束 | 实现 |
|---|---|
| Java 8 / 旧 Bukkit | 共用技能代码只调用低版本已有的实体/事件 API；未使用新版 DamageSource 构造原生伤害。 |
| MM 4 / MM 5 类加载隔离 | 启动期探测包名后分别注册 `Mythic4Skills` / `Mythic5Skills`。 |
| MM 4.1 参数截断 | 从完整技能行读取 SX 参数，保留 `al=攻击力=100` 中的第二个等号。 |
| SX 原生表达式 | 两代 MM 均保留嵌套表达式中的分隔符；SX 数值和 Lore 共用每目标独立 Handler。 |
| 旧 SX-Item 锁定变量 | 对仓库内 4.5.0 API 包做字节码读取，确认三参数 protected 构造器和变量表接口；上下文同时注入 lockMap/otherMap，避免旧版无 `#` 变量未读取 otherMap。 |
| MM 4.1 无 PlaceholderString | 回退 `SkillString.parseMobVariables`；后期 MM 使用 metadata 解析并缓存解析器。 |
| MM 4 等级返回类型变化 | 反射读取 `Number` 的字符串表示，不绑定 `int` / `double` 描述符。 |
| MM 4 早期无 ActiveMob.getDisplayName | 回退 Bukkit 实体显示名，再回退怪物内部名。 |
| 怪物出生配置 | MONITOR 显式检查取消，不依赖出生事件实现 Bukkit Cancellable；读取 MM 配置对象的 SXAttribute 列表。 |
| 出生等级与属性来源 | 反射兼容 getMobLevel 的 int/double 返回值；独立 mythic-mob:spawn 来源，全部求值后写入，重复通知不重抽。 |
| MM 5.13 移除旧 SkillMechanic 构造器 | 直接实现稳定的 `ITargetedEntitySkill` 接口。 |
| 旧服不支持的新原版属性 | 继续使用 SX 已有的属性注册与版本门控。 |
| 普攻和技能伤害区别 | 技能不扣除原版攻击基值、不剔除弓属性、不消耗普攻武器耐久。 |
| 取消、免疫、嵌套、事件归属 | 原生 damage 调用、事件对象绑定、finally 清理、8 层伤害技能递归上限。 |
| Folia 全局/错误区域入口 | 先跟随施法者实体调度，再检查两端所有权；MM 伤害标记仅覆盖实际执行。 |
| Folia 跨区域非战斗技能 | 两端快照、公式玩家区域求值、目标区域写入；不会阻塞线程等待另一区域。 |
| Folia 退役/停用/过载 | 调度退役回调、完成状态去重、停用清理、1024 个全插件在途施法上限。 |
| Folia 跨区域完整伤害/任意脚本 | 在副作用前明确拒绝；不伪造同步线程或静默改为匿名扣血。 |
| 继承/计算来源的生命周期 | 原始数值快照、禁止自身继承、计算保留到期时间与层数、快照不可持久化。 |

## 未执行的验证

未执行构建（用户未要求）。没有编译或运行新增 JUnit 用例，也未启动实际 Bukkit/Paper/Folia 与 MM 服务端。
新增回归用例覆盖列表解析、早期等号截断、动态负数/溢出、快照隔离、取消、嵌套与异常状态恢复；
另有 SX/MM 标记隔离、先展开再计算、完整 Lore/多行词条、缺少引擎和非有限结果的回归用例。
表达式测试中的替身用于检查接线与顺序，不代表原生引擎运行测试。
Folia 接力用例覆盖分阶段所有权、非阻塞返回、同步失败、调度拒绝、实体退役、迟到回调、停用与异常清理；
调度替身在跨区域读取实体时立即失败，但不替代真实服务端的线程检查。
出生配置用例覆盖节点优先级、配置副本、旧/新等级返回类型、出生别名嵌套 SX 公式、固定 Lore 与无目标上下文拒绝。
这些用例仍需在获准的测试环境执行，不能把本记录视为 JUnit 已通过。

ABI 检查覆盖的是新技能与出生配置使用的接口边界，不是 SX、SX-Item、所有第三方属性脚本的完整运行证明。
未逐一验证所有 MM 小版本、MM 4.0、付费分支、开发快照或历史 Minecraft 补丁组合；
不能据此宣称每一种安装组合都已实测通过。

后续实际服务器验收应覆盖以下行为：

1. 旧服 Java 8 + MM 4、现代服 + MM 5 的冷启动注册和 `/mm reload`；缺少 MM 时 SX 正常启用。
2. 玩家/怪物施法、单体/范围目标、`a=0` 的属性伤害、普通伤害基数与百分比基数。
3. 暴击、吸血、反伤、药水、元素/抗性与 JS 属性；普通近战和弓攻击没有变化。
4. 保护插件取消、创造/无敌目标、受伤间隔、破甲、护甲减伤及击杀归属。
5. 同步伤害触发器嵌套时不串用属性、技能变量按目标解析、异常后上下文清理。
6. 来源叠层/刷新/到期/移除、继承时不重复映射、Count 保留时间与层数、持久化失败反馈。
7. 治疗取消与生命上限、装备刷新、API 动作触发；Folia 从全局线程进入同区域执行。
8. `a/bam/m/dm/d/ms/al` 分别使用 SX 随机、计算、锁定和 PAPI；验证锁定结果在同一目标共享、多个目标/后续施法隔离。
9. SX RandomString 多行 Lore、冒号范围、嵌套 MM 等级变量；持续时间/层数小数、未知变量和关闭引擎时正确失败。
10. Folia 不同区域的增益/治疗/继承接力；两端采样、PAPI 玩家归属、施法期间传送/下线、来源并发变更。
11. 跨区域 Damage/Trigger 与未支持的 MM 标记在副作用前拒绝；排队成功不误作即时生效；过载与停用释放任务。
12. 两代 MM 出生配置、整数/小数等级、出生取消、装备先加载、各行共享锁定结果；普通装备刷新与重复出生通知不重抽。
13. 出生来源与技能 Buff 同时存在、死亡清理、新配置仅影响新怪；出生公式错误时没有半份来源写入。
